# Parallax 해커톤 랜딩 페이지

HTML·CSS·JavaScript로 만든 프로젝트 소개용 초안입니다. 설치나 빌드 없이 브라우저에서 열 수 있습니다.

## 미리보기

`index.html`을 브라우저로 엽니다. **데모 미리보기**를 누르면 시연 흐름 예시가 펼쳐집니다.

## 수정할 곳

- `index.html`에서 프로젝트 이름, 한 문장 소개, 해결하려는 문제, 데모 내용을 수정합니다.
- `styles.css`에서 색상, 타이포그래피, 화면 배치를 수정합니다.
- `script.js`에서 데모 버튼의 동작을 수정합니다.
